# quanttide-work

量潮知识工作

## 概述

quanttide-work 是量潮知识工作领域，围绕知识工作的方法、流程、工具与规范，沉淀领域第二大脑。

## 领域边界

- **工作方法**：知识工作的流程、习惯与纪律
- **工作工具**：知识工作云、工具箱与工作台
- **工作规范**：章程、手册、规范与教程
- **工作沉淀**：文集与画廊

## 子模块

| 路径 | 说明 |
|------|------|
| `apps/qtcloud-work` | 量潮知识工作云 (git submodule → qtcloud-work) |
| `packages/quanttide-work-toolkit` | 知识工作工具箱 (git submodule → quanttide-work-toolkit) |
| `examples/default` | 知识工作实验室 (git submodule → quanttide-laboratory-of-knowledge-work) |
| `docs/bylaw` | 知识工作章程 (git submodule → quanttide-bylaw-of-knowledge-work) |
| `docs/handbook` | 知识工作手册 (git submodule → quanttide-handbook-of-knowledge-work) |
| `docs/specification` | 知识工作规范 (git submodule → quanttide-specification-of-knowledge-work) |
| `docs/tutorial` | 知识工作教程 (git submodule → quanttide-tutorial-of-knowledge-work) |
| `docs/essay` | 知识工作文集 (git submodule → quanttide-essay-of-knowledge-work) |
| `docs/gallery` | 知识工作画廊 (git submodule → quanttide-gallery-of-knowledge-work) |
